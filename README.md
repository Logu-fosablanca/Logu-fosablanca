## About me

I'm an AI Software Engineer at **IDFC First Bank**, building production conversational agents and the framework they run on. My work sits where applied AI meets distributed systems: agent orchestration on LangGraph and CrewAI, multi-turn state and memory, and the evaluation, safety, and observability layers that let these systems run inside a bank. I care about reliability, evals-driven development, and keeping LLM systems cost-aware and easy to debug in production. I also have a soft spot for tooling that other engineers can pick up without reading a manual.

**What I'm building right now**

- **JARVIS**, a conversational AI platform for stateful banking agents that complete real financial tasks over voice and text.
- **Soprano-SDK**, a YAML-driven agent framework on top of LangGraph and CrewAI, so agents are declarative instead of hand-coded.
- Small, focused open-source libraries around intent classification and agent workflows.
